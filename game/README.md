# Electronic Detective — оболочка для игры

Игра Ideal (1979) в окне. По умолчанию её ведёт собственная программа (`machine.py`): те же правила, табло и звуки,
что у оригинала, но дело раздаётся по-настоящему случайно и ROM не нужен. С `Shift` запускается оригинал:
эмулятор процессора TMS0980 исполняет настоящий ROM.
Правила для игрока — `..\PLAYER_RULES.md`. Карточки подозреваемых — бумажные или PDF (на экране их нет).

## Запуск

1. Python 3 и `pygame-ce`: `python -m pip install pygame-ce`.
2. Двойной щелчок по `play.bat` (или `python elecdet_game.py [путь к ROM]`).
3. ROM нужен только для оригинала (`Shift+ON`). При первом таком включении программа попросит файл `elecdet.zip`
   из MAME или папку с файлами `mp6100a`, `tms0980_common1_instr.pla`, `tms0980_common1_micro.pla`,
   `tms0980_common1_segment.pla`, `tms0980_elecdet_output.pla`. Файлы проверяются по SHA1 из MAME. ROM в комплект
   не входит. Путь запоминается в `settings.json`; чтобы выбрать другой, удалите из него строку `rom`.

## Управление

| Клавиша | Кнопка |
|---|---|
| `0`–`9` (и цифровой блок) | цифры |
| `S` | SUSPECT |
| `Q` | PRIVATE QUESTION |
| `A` | I ACCUSE |
| `Enter` | ENTER |
| `T` | END TURN |
| `O` / `X` | ON / OFF |
| `Shift` + `O` (или Shift + щелчок по ON) | включить оригинальную игру (расклад раздаёт прошивка) |
| `Пробел` | подсмотреть закрытый частный ответ |

Кнопки на экране тоже нажимаются мышью. Настоящий прибор не замечает нажатия короче ~40 мс и путается,
если нажать клавишу, не отпустив предыдущую; оболочка это сглаживает: каждое нажатие удерживается не меньше
0,1 с, клавиши подаются по одной.

## Два режима: своя машина (по умолчанию) и оригинал

Обычное включение (`ON`) — своя машина. Чтобы сыграть в оригинал, включите машину, удерживая `Shift`
(клавиша `O` или щелчок по `ON`). Оба варианта перечислены в строке ответа, пока машина выключена;
во время партии режим не показывается. Чтобы сменить режим, выключите и включите машину.

У оригинала нет генератора случайных чисел: расклад получается прокруткой таблицы, и от этого остаются закономерности,
которыми можно пользоваться (они описаны в `..\research\SPOILERS.md`). Своя машина раздаёт дело случайно (`rules.py`),
а ведёт игру так же, как оригинал: ввод, `EE` и `END`, лимит вопросов, обвинение, табло.

- Уходят: «запретные» номера жертвы и убийцы, связь букв и адресов мест с ролями, связь орудия и вида алиби
  с конкретными людьми, зависимость дела от длительности нажатия `ENTER`.
- Остаются (это правила игры): место на троих без убийцы и оружия, правила ответов про отпечатки.
- Отличия от оригинала (сделаны нарочно; сам оригинал доступен по `Shift+ON`):
  - повторный `SUSPECT` до `ENTER` очищает табло (оригинал показывает `EE`, хотя ввод не сломан);
  - отклонённая клавиша режима отменяет ввод: следующий `ENTER` даёт `EE` и ничего не стоит. В оригинале прежний режим
    остаётся в силе, и номер «второго подозреваемого» читается как номер вопроса;
  - клавиша `I ACCUSE` не «забывает» подозреваемого хода (в оригинале после неё можно выбрать другого без `END TURN`);
  - частный вопрос можно задать только выбранному в этом ходу подозреваемому; жертву допросить нельзя
    (оригинал отвечает за предыдущего подозреваемого);
  - вопросы принимаются строго по карточкам (оригинал у некоторых подозреваемых принимает один лишний);
  - партия не выключается сама (в оригинале — примерно через 4 минуты после конца);
  - клавиши принимаются всегда (оригинал пропускает короткие нажатия, пока табло мигает).
- Звуки — те же тоны, что издаёт оригинал: они измерены и записаны как ноты в `sounds.py`.
- Рекорды режимов хранятся отдельно (`records_fair` — своя машина, `records` — оригинал).
- Проверка: `..\research\emu\diff_machine.py` подаёт своей машине и прошивке одно дело и одни и те же случайные клавиши
  и сравнивает табло после каждой;
  для сверки своя машина включается в режиме `rom_like`, где перечисленные отличия выключены.

## Что добавляет оболочка

- **Строка ответа** под табло — расшифровка табло по-английски: имена, места, текст вопроса.
- **Шторка** (2–4 игрока): ответ на частный вопрос закрыт; держите пробел или кнопку мыши на табло.
- **Счёт**: после `END TURN` в строке ответа — итог хода вместе с приглашением следующему игроку; в конце — итог партии.
  Внизу окна всегда остаётся подсказка по клавишам.
  Ход засчитывается, если в нём допрашивали; вопрос — если машина ответила (не `EE`/`END`).
- **Рекорды** (одиночная игра, по уровню): меньше ходов, затем меньше вопросов; хранятся в `settings.json`.

## Как ведёт себя машина (проверено на эмуляции)

- После `ON` ~6 с звучат «бонги», клавиши в это время не работают.
- Лишний частный вопрос сверх уровня → `END`; вопрос не с карточки → `EE`.
- Неверное обвинение, когда в игре остаются другие: мигает `N0`, игрок выбывает,
  следующему нужно сначала нажать `END TURN`. Когда ошиблись все — машина показывает убийцу (`NNd1d`).
- После разгадки можно продолжать допрос; машина выключается сама через ~4 мин, `END TURN` продлевает.

## Файлы

| Файл | Что |
|---|---|
| `elecdet_game.py` | окно, звук, расшифровка табло, счёт |
| `board.py` | плата прибора и загрузка ROM (для оригинала) |
| `machine.py` | своя машина: ввод, ход, табло, звук (без ROM) |
| `rules.py` | правила: раздача дела, алиби и ответы (спойлеры) |
| `sounds.py` | звуки как ноты прямоугольных тонов (получено `research\emu\sounds.py`) |
| `tms0980.py` | ядро процессора (копия `research\emu\tms0980.py` с таблицами для скорости; побайтно сверено) |
| `selftest.py` | проверка без окна: ROM, расшифровка, счёт, выбор ROM — `python selftest.py <ROM>` |
| `test_private.py`, `test_score.py`, `test_multi.py` | проверки в окне на реальной партии (~1,5 мин каждая) |
| `probe_multi.py`, `probe_poweroff.py` | исследование поведения машины (несколько игроков, автовыключение) |
| `probe_patent.py` | проверка утверждений патента: `EE` (вопрос не с карточки) съедает вопрос хода; без `END TURN` → `END`/`EE` |
